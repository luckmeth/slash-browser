Connect to your database

This app is the operations side of Slash: the advert review queue, pricing, releases and browser configuration. It needs one key to reach your Supabase project.

The service_role key bypasses every access rule in the database. It is stored encrypted by Windows and tied to this user account — copying this program to another machine gets a setup screen, not your data. Do not paste it anywhere else.

Not the anon key — that one authorises nothing and every page would come back empty.
